# 词间 Android 完整版实施计划

更新：2026-10-13。本计划完整替代此前的「精简离线版」计划。

## 1. 已确认的目标与交付范围

- 平台：Android 10 及以上，个人使用，以签名 APK 安装；首版不做应用商店、多用户开放注册或 iOS。
- 功能：迁移网站当前已实现的全部学习功能，并完善手机交互；不新增 AI 生成、智能判分、推送提醒等未要求的功能。
- 数据：离线优先，首次须联网登录现有词间账号并完整下载记录，以后离线可持续学习；联网自动与原网站双向同步。
- 访问：用户已明确选择让网站登录页可公开访问，取消 Sites 外层访问限制，仍由词间账号认证保护所有个人数据。只有通过认证与权限测试、部署验证后才执行该访问设置变更。
- 品牌：名称「词间」，保留现有视觉风格；Android 包名 `com.wordweave.offline` 保持稳定，展示版本从 `0.1.0` 开始。包名的 offline 不限制在线同步能力。
- 交付：签名 release APK、SHA-256、源码、可重现构建说明、安装/升级/备份说明和测试报告。后续升级使用同一包名与签名，保留用户数据。

### 已核实的现状

网站为 React/Vinext + Cloudflare Worker + D1，已有用户名密码登录和单账户注册限制。核心学习数据当前存于一份 State JSON；在线写入有 revision 比较更新和最近 1000 项操作编号去重。网页无法可靠离线冷启动或持久保存失败操作。

内容包含 2163 个内置义项（100 个完整内容、2063 个基础内容）与 61 篇阅读。六级 58 篇覆盖 2128 个带标签义项；四级 3 篇覆盖 89 个带标签义项，两级有重叠。四级内容不宣称覆盖完整考纲。

代码实际提供阅读和自评卡片练习；文档中的「逐词、多词、全部隐藏练习」不是现有界面功能，不能当成已实现功能迁移。现有学习算法与阅读验证脚本已通过。

## 2. 完整版页面与功能

底部导航采用「今日 / 阅读 / 词库 / 记录 / 我的」，复习作为今日、阅读词条和词库可进入的专注流程。

| 页面或流程 | 实现内容 |
| --- | --- |
| 今日 | 继续阅读、到期复习、今日阅读/作答数量、阅读覆盖率、三个能力方向的待复习数量、未来七天负担、最近练习 |
| 初测 | 可跳过的 5 词起点自评，熟悉词安排低频抽查，不计为考试答对或掌握 |
| 阅读 | 四六级切换、目录、未读优先、继续阅读、重读、点词释义/随句释义、词条详情、朗读、记录已读 |
| 词库 | 中英文搜索、级别和熟悉度筛选、详情、例句/译文/搭配、来源、个人联想编辑、自评熟悉度、主动加入复习 |
| 快速浏览 | 逐个翻词、合并训练方向、词义与已有例句、朗读；不改变成绩、复习间隔或新词额度 |
| 复习 | 英文认义、中文回忆英文、具备材料的词条提供语境理解；回答、提示、揭晓、自评、跳过、只看答案和本轮总结 |

| 导入 | JSON 词表模板、格式与来源校验、去重预览、导入结果；导入词进入查询与复习，不自动生成阅读文章 |
| 我的 | 账号、同步状态/手动同步、备份与恢复、学习偏好、浅色/深色/系统主题、语音设置、版本和数据说明 |

### 学习规则

- 使用现有学习算法，不为移动端另写一套计分规则。三种能力独立排程，基础词只开放已有材料支持的方向。
- 独立答对按 1、3、7、14、30、60 天排程；答错 10 分钟后重试；提示答对 1 天后重试；同方向间隔不足 24 小时不增加成功阶梯。
- 阅读完成记录接触，不自动标记掌握或测试正确。详情提供「开始练习」「陌生，加入复习」，避免新用户阅读后没有复习入口。
- 跳过、直接看答案与快速浏览不记成绩。新词额度沿用网站语义，不阻止阅读和到期复习。
- 今日统计继续按北京时间划分，学习事件记录实际发生时间；补传时不改成联网日期。

### 手机体验

适配手势返回、状态栏/导航栏安全区、键盘避让、字体放大、深色模式、横竖屏与前后台切换。主要点击区域不小于 44 CSS px。返回优先关闭弹层，再结束当前练习、回到主页面。已提交成绩立即持久化；未提交草稿不计分。

使用系统英文 TTS，优先选择离线语音；缺少语音资源时明确提示并提供设置入口，文本学习不受影响。文件导入导出走 Android 系统文件选择与保存，不申请整个存储空间权限。主题等设备偏好不跨端覆盖。

## 3. 工程、存储与同步设计

### 工程边界

- 在 `mobile/` 使用独立 React + Vite + Capacitor 8 构建，打包本地 HTML、JS、字体与全部内置词库/段落。复用网站纯学习、阅读和校验模块；移动 UI 不依赖 Next 服务端运行时。
- 新增本地数据模块、同步模块及 Android 原生适配。页面通过数据模块读取和提交动作，不直接写 SQLite、发同步请求或自行合并云端状态。
- 保留工作区现有未提交修改。共享代码调整需同时验证网站和手机，避免把网站当前优化工作覆盖掉。
- 使用现有 Android SDK；由匹配 Capacitor 的 Gradle Wrapper 构建，必要时在工程的忽略目录准备兼容 JDK，不替换系统 Java。

### 本地存储

SQLite 按稳定账户 ID 保存已确认云端基线、云端修订号、本地可见状态、持久待同步操作、冲突信息和恢复前副本。本地 UI 偏好单独保存；初始内置内容随 APK 分发，附内容版本与校验值。

每次学习操作生成固定 UUID，捕获发生时间和本设备顺序；先在本地事务中同时提交状态与待同步操作，再向页面返回成功。对现有会原地修改 State 的函数，必须先复制状态，避免保存失败后界面已前进。磁盘满、事务失败或读取异常时保留现有记录，不自动重置。

客户端同步只允许一个任务运行：应用启动/回到前台、前台网络恢复、学习保存后触发，前台周期性检查和手动重试作为补充；重试使用退避。首版不承诺应用被系统彻底结束后即时同步，下次打开继续补传。

同步状态显示「已保存在本机」「待同步 N 项」「同步中」「已同步」「需要重新登录」「存在冲突」，不把本地保存成功显示为云端同步完成。

### 新增服务端接口与类型

- `/api/mobile/auth`：复用现有账号验证、密码算法、限流和单账户约束，建立/撤销独立移动设备会话。移动会话只用有效 Bearer 凭据访问移动接口，网页继续使用 HttpOnly Cookie 与严格来源校验。
- `/api/mobile/bootstrap`：认证后返回稳定 userId、账号名、当前 State、revision、generation、协议/内容版本与服务端时间；只有完整写入本机后才完成首次初始化。
- `/api/mobile/sync`：批量接收待同步动作，返回逐项确认、冲突、最新权威快照及 revision/generation。首版优先使用完整快照，避免把现有网页 delta 错误合并到含未提交操作的本地状态。
- `/api/mobile/restore`：联网执行全量恢复，要求匹配服务端 revision/generation，保存安全副本后建立新数据代次。
- 移动动作最少包含 `operationId`、`deviceId`、`deviceSequence`、`occurredAt`、`generation`、`type` 与动作内容。阅读动作引用稳定 passageId/contentVersion，服务端从自身内容取段落，不信任客户端提交的正文或词表。
- D1 增加移动会话、同步操作日志/回执、数据代次与迁移基线。操作回执与权威状态在同一个原子批次中提交，使用 revision 条件写入防止并发覆盖。
- 现有网页接口与返回格式继续兼容，但写操作也进入统一同步记账，确保网页修改不会绕过新冲突规则。

### 时间与合并规则

- 已确认快照与本地待同步动作分开保存。收到服务端结果后，原子更新基线、删除已确认项、重新应用剩余项，禁止直接用云端快照覆盖未同步成果。
- 练习按唯一操作 ID 去重，持久回执不依赖现有 1000 项数组。相同 ID 携带不同内容应拒绝。错误或冲突保留原操作，不无限自动重发。
- 练习按发生时间与稳定顺序重建受影响词条的排程，包含初测/加入复习的影响；较早的离线练习晚到时，不得简单覆盖成更早的 last/due。旧数据作为迁移基线，既有历史结果与编号完整保留。
- 首次初始化建立服务端时间锚点；保留设备事件时间和顺序。明显时钟回退或超前的动作进入可见的待处理状态，不静默按接收时间记账。
- 阅读完成按段落 ID 合并并去重。其他设备切换词表后，仍可接收原词表的有效离线阅读记录。
- 不同词条的联想分别合并；同一词条发生并发编辑时保留双方文本，展示选择，禁止静默覆盖。设置按字段合并，同字段以服务端接收顺序确定；主题和设备语音设置保留本机。
- 导入维持原有词义去重规则。若跨端同一自定义义项使用不同 ID，服务端返回 canonical ID 映射，本地事务内更新相关引用及待同步动作；同 ID 对应不同义项则显式报冲突。
- 全量恢复会增加 generation。其他设备尚未上传的旧代次操作停止自动合并，提供导出保留和重新载入入口，避免恢复后旧记录再次被注入。

### 账号与网络访问

首次联网登录后，短期断网和移动会话到期都不清空本地档案。会话到期仅暂停同步，提示重新登录；原账号重新验证后继续补传。数据始终按稳定 userId 分区。

移动会话沿用 14 天有效期并支持撤销，随机凭据仅在 Android Keystore 保护的加密存储保存，服务端只存摘要。APK 不包含注册密钥、密码、Sites 绕过凭据或后台密钥。通过原生 HTTPS 传输访问固定服务地址，不放宽网页全站 CSRF 校验。

主动退出前说明未同步数量，提供先同步或导出选项；不因普通网络失败或 401 自动删除离线成果。账号切换/清理必须明确确认并完成数据分区处理。单账号首次注册规则沿用现有网站，不把登录页公开等同于开放注册。

## 4. 备份、迁移和发布

### 备份

保留兼容格式 `{app:'wordweave', schema:1, exportedAt, state}`，完整包含 settings、reading、progress、notes、familiar、learned、custom、events、operations。设备会话和同步凭据不进入备份，本地 revision 不冒充网站 revision。

导出先标明是否含未同步成果，随时可保存本机完整备份。完整账号恢复仅在线进行：先处理本机待同步操作，校验并预览备份、导出当前安全副本，再确认替换云端及本机基线。取消、校验失败或并发版本不匹配都不改变现有数据。

旧网站备份继续兼容，包括没有 reading 字段的历史备份。现有限额（4 MB 请求/文件、State 体积、自定义词与历史记录数量）通过共享校验保持一致；超限不静默截断或丢弃，提供明确错误与本机数据保留能力。

### 旧数据迁移

先为现有单账号的完整 State 建立不可变迁移基线和 generation，不重建密码、不更换用户 ID、不删除旧历史。数据库变化采用追加迁移，先在隔离数据上验证。网页旧协议继续可用，新移动接口先通过受保护环境验证。

发布前保留账号备份和原站点版本。部署顺序为：兼容后端与迁移 → 网页验证 → 移动同步联调 → 未登录访问与认证测试 → 按用户选择调整 Sites 外层权限 → 签名 APK 交付。

若后端异常，先停用移动写接口并保留手机待同步记录；应用维持离线功能。回退使用理解新日志/代次的兼容版本，不直接回退到绕过操作日志的旧写入实现。

### 分阶段完成

1. 完整页面结构、共享学习逻辑和本地持久化，覆盖所有学习功能。
2. 账号初始化、移动会话、同步操作与冲突规则、网站兼容写入。
3. JSON 导入/导出、全量恢复与代次、语音、系统文件交互和生命周期适配。
4. 全量回归、生产迁移与访问切换、签名打包、升级验证和交付文档。

阶段是实施顺序，不削减完整版本的最终交付范围。

## 5. 测试与验收

- 学习规则：沿用现有学习/阅读/日期/同步测试；验证三能力独立、提示/跳过/初测不误记、阅读去重、基础词能力限制。
- 本地可靠性：首次完整初始化后飞行模式冷启动；连续阅读/作答/编辑联想/导入；强制结束后恢复；磁盘写入失败不吞答案。
- 双端同步：网站与手机交替学习、同时答题、长时间离线、超过 1000 操作重试、服务端已提交但响应丢失、批次中断与重新连接。
- 冲突：乱序练习不错误回退排程；笔记双版本；重复导入 ID 映射；词表切换后补传阅读；跨设备恢复阻止旧代次回灌。
- 身份：首次登录失败不创建半初始化档案；凭据到期保留本地数据；重新登录继续上传；所有未认证个人数据接口拒绝访问；网页来源保护与登录限流继续有效。
- 备份：网站旧备份/手机新备份往返；未知版本、损坏内容、重复义项、超限、取消与版本冲突均不破坏原记录。
- 手机：Android 10 与较新系统，安全区、手势/实体返回、大字体、输入法、深色模式、无英文语音、文件选择取消、横竖屏和前后台切换。
- 发布：验签、安装、同签名覆盖升级保留数据；网络断开时核心功能可用；前台联网后两端数据最终一致。
- 报告明确区分已执行的单元/接口/浏览器/模拟器/真机测试；无设备时不声称真机验收通过。
