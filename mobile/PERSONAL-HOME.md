# 个人主页

Android 0.1.7 · 2026-10-20。

| 区域 | 功能 |
| --- | --- |
| 个人资料 | 六种内置头像、24 字以内昵称、80 字以内签名；空昵称回退为账号名 |
| 学习足迹 | 累计已读篇数、接触词数、练习次数，覆盖四级和六级；接触不等于掌握 |
| 学习偏好 | 词表、词义提示、新词上限、外观 |
| 同步与账号 | 登录账号、同步状态、冲突处理、退出登录 |
| 数据与备份 | 保留学习备份、恢复及词表导入功能 |
| 关于词间 | 版本及内容信息 |

## 保存边界

个人资料使用账号标识隔离，作为可选字段存入现有本机档案。旧档案无需迁移；资料损坏或账号不匹配时回退默认资料，不影响学习记录。资料修改先完成持久化，再刷新界面并提示成功；失败保留草稿，可重试。

资料不更改登录用户名，不进入学习同步队列，也不包含在学习备份中。退出登录锁定资料，同账号重新登录后恢复。编辑草稿仅在本次登录界面中保留，关闭弹层、切换 Tab 不丢失；重启或退出登录不会保存草稿。

## 交互

主页复用主 Tab 缓存；二级页退出动画结束后释放，返回主页恢复滚动位置。使用现有 320 ms 转场、点击反馈和减少动态效果设置，未改动学习算法。返回操作先关闭选择器，再退出二级页。

## 验证

已通过 64 项手机端功能测试、60 项浏览器检查（含 22 项个人主页检查）和 10 项原生单元测试。覆盖资料校验、账号隔离、持久化失败、重试、刷新恢复、累计指标、二级导航、动画结束透明度、窄屏大字号和深色外观。APK 沿用原证书，包内 5 个页面资源与最终构建一致；release lint 为 0 错误、17 项既有提示。

压力检查首次与 Android 构建同时进行时，450 ms 快照观察到透明退场节点尚待 React 提交清理，未发生透明度回弹。构建结束后原检查复测通过，200 次切换也未累积页面或监听器；该次异常及性能样本保留在 `release/wordweave-0.1.7-verification.json`。

浏览器检查不能替代 Android 真机验收。输入法、返回手势、覆盖安装、长期运行及真机帧率仍需设备验证。
