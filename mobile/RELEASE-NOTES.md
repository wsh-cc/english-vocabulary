# 词间 Android 0.1.0

构建日期：2026-10-14。应用包名：`com.wordweave.offline`，最低 Android 10。

## 安装与首次使用

将 `release/wordweave-0.1.0.apk` 复制到手机并按系统提示安装。使用现有词间网站的用户名和密码登录；首次登录需要联网下载记录，之后可离线阅读、查词、练习与保存。在线时自动同步，也可在「我的」手动同步。

同步后端发布完成前，首次登录入口不能使用。当前本地 APK 已完成；网站发布需要托管仓库推送授权，发布结果将另行确认。

保留单人账号规则，网站注册仍需私人注册密钥。应用不包含密码、注册密钥或后台凭据。英文朗读需要手机已安装离线英文语音，可从「我的」打开系统语音设置。

## 已完成的功能

今日安排与可跳过的初测、2163 个内置义项、61 篇阅读、点词/随句释义、阅读目录与重读、词库筛选、三方向自评练习、提示/跳过/只看答案、快速浏览、个人联想编辑、JSON 词表导入、学习记录、备份恢复、主题和系统文件选择。

四级现有 89 个带标签义项，六级 2128 个，两级有重叠。基础词条不提供缺少材料的语境题。阅读接触、自评熟悉和初测不计为掌握。导入词可查询和复习，不自动编入内置阅读。

## 数据与升级

学习动作先写入 SQLite 和持久同步队列，再更新页面；重试保持固定操作编号和发生时间。云端冲突在「我的」处理。登录到期不会删除离线记录。恢复备份需要联网，会替换账号记录并建立新代次；旧设备的未同步操作需要先导出保留再载入。

JSON 备份与网站 schema 1 兼容，包含完整学习状态；恢复前的安全副本可导出。学习状态按实际 UTF-8 字节校验，云端单份状态上限为 1,900,000 字节；超限不截断记录。完整本机备份可导出保留，超过网站限额时会明确提示。

后续版本沿用同一包名与签名，可覆盖安装。卸载会删除本机数据，卸载前先完成同步或导出备份。签名私钥保存在工程忽略目录，不能提交或公开。
