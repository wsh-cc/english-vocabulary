- 修复首次登录后报「缺少本机学习档案或修订号」：JavaScript 的小整数修订号在 Android 中解析为 Integer，旧接口只接受 Long，错误地把首次修订号 0 当作缺失。新接口严格接收可安全递增的非负整数，保留修订冲突检查。

- 用户已确认当前手机访问站点需要可用的代理网络；此版本不改变站点的网络可达性。首次登录及在线同步时，需确保词间 APP 也能通过可访问站点的网络连接。
